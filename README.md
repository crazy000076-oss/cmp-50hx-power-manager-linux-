# Smart Power Manager for NVIDIA CMP 50HX (Linux Native)

Нативный менеджер энергопотребления на C++ для видеокарт NVIDIA CMP 50HX под Linux (Ubuntu Server). 

### Что делает эта программа?
* **В простое:** Автоматически зажимает видеокарту в экономичный режим **P3 (44W / 300MHz)**, не позволяя ей вхолостую греть сервер на заводских 75-93W.
* **Под нагрузкой:** Мгновенно фиксирует запуск ИИ-тестов или нейросетей по датчику линий питания (Power Usage) и срывает оковы, переводя карту в максимальный боевой режим **P0 (170W / ~1920MHz)**.
* **После работы:** Сама возвращает карту в ледяной покой P3 стабильно и без зависаний.

### Быстрая сборка и запуск в 3 шага

**1. Клонируйте код и скомпилируйте бинарник:**
```bash
g++ -O3 manager.cpp -o cmp_linux_manager -ldl
```

**2. Запустите менеджер в фоновом режиме (как службу):**
Укажите путь к вашему патченному драйверу в `LD_LIBRARY_PATH` (например, `/home/1/nvidia-patched-610`):
```bash
export LD_LIBRARY_PATH=/path/to/your/patched-driver
sudo nohup ./cmp_linux_manager > manager.log 2>&1 &
```

**3. Как проверить работу:**
Запустите `nvitop` или `nvidia-smi`. В простое вы увидите стабильный режим P3 и 44W. Запустите любой CUDA-тест — карта мгновенно улетит в P0 на полную мощность, а после закрытия теста вернется обратно в P3.
